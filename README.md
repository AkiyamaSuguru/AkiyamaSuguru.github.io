# Jay Ma · Personal Homepage

A personal homepage in a NASA / SpaceX-inspired style, ready for GitHub Pages.

- `index.html` holds the page: content, styles and scripts.
- `portrait.svg` is the anime-style profile picture (suit and tie).
- `preview.html` shows the site in desktop and phone frames plus every section. It is for local viewing only and is git-ignored.

## Deploy

1. Create a public repo named **`AkiyamaSuguru.github.io`** on GitHub.
2. Push `index.html`, `portrait.svg`, `README.md` and `.nojekyll` to the `main` branch.
3. In the repo: **Settings → Pages → Source: Deploy from a branch → `main` / root**.
4. Visit https://akiyamasuguru.github.io
